# Valkyrien Mechanic

**Valkyrien Mechanic** is a Valkyrien Skies 2 that attempts to add various features from sandbox game Scrap Mechanic, featuring the iconic connection system and a bit more.

![Connection system demonstration](https://cdn.modrinth.com/data/cached_images/25efca66724001af7320bdb6e87a6800d18254ab.png)

*Connection system demonstration on a simple car*

---

## Features

Right now it features (as for version 1rc):

- Connection system via Connector tool
- Gas Engine
- Thruster
- Button
- Switch
- Bearing
- Seat

You can learn more about the items with tooltips in game!

## Planned features

- More interactive blocks from Scrap Mechanic
- Further survival integration (mobs, fuel system)
- Separate redstone connector tool (making Scrap Mechanic-like connections for redstone and Create mod stuff)
- Wheels
- Create integration

## Ports

- **1.21.1** - when VS2 team makes an official 1.21.1 port

## Dependencies

- Valkyrien Skies 2.4.11 and newer (the bearing is broken with the newest playtest, better use 2.4.11)
